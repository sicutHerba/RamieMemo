## 🌟项目愿景

"苧麻备忘录"试图收集那些应该被我们记住的声音。

这里不是一间完备的档案馆，而是一册轻便、可随身携带的备忘录。

这里永远是不完整的。无论如何努力，没有人能够记下所有的声音。正因欠缺，我们才必须学会包容。
